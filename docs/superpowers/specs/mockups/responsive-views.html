Implementation notes

  • Type scaling uses clamp() on hero / section headings — fluid, no breakpoint jumps for display sizes.
  • Layout grid changes use standard @media (min-width: 1280px) and @media (min-width: 768px) — desktop-up media queries.
  • The TOC's IntersectionObserver still works at every breakpoint, but on tablet/mobile the TOC is display: none, so the observer simply has no target and does nothing.
  • Cover image swaps aspect ratio via aspect-ratio at breakpoints — same image, different crop logic. (Real implementation may need <picture> with art direction for different image crops.)
  • Grid background spacing on .image-showcase shrinks on mobile (background-size: 18px instead of 28 px) so the dotted pattern still reads at small sizes.
