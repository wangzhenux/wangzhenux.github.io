Responsive design plan (will detail in spec)

Three breakpoints, designed-mobile-up:

  • 320–767 px (mobile): single column, padding shrinks 56→24, hero title 60→32, meta strip becomes 2-column grid, three-card rows stack, phase blocks become number → text → image vertical flow, side-by-side blocks stack image-then-text. Mobile slices shown above.
  • 768–1199 px (tablet): two-column where it makes sense (history rows, two-col blocks, three-card row → 1×3 stays). Hero title 60→48. Padding 56→40.
  • 1200+ px (desktop): as designed in the mockups. Maximum content width 1200, body column ~1080, narrow text 32ch.

Type scales fluidly with clamp() on hero/section headings — display sizes shrink proportionally without breakpoint jumps. Images use aspect-ratio + object-fit: cover so covers stay shapely on any width. CSS custom properties already centralize spacing tokens so we set --pad-section once per breakpoint.
