Using dark mode

Force dark on a page: <html data-theme="dark">

Force light (override system): <html data-theme="light">

Follow system (default — no attribute needed).

To toggle dynamically: read and write document.documentElement.dataset.theme. Persist to localStorage.

Non-negotiables in dark

Forest must be #7A9158 in dark — the light #3D4A2E disappears on near-black.

Surfaces stay warm (brown-black) not cool-gray. Never use pure #000.

Chip-hot inverts: --ink is now off-white, so text on ink chips must be near-black.

Donut hole stays var(--paper) so it punches out correctly.
